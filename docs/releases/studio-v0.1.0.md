# Studio 0.1.0 版本说明与验收记录

> 版本：`0.1.0`（tag `studio-v0.1.0`）
> 发布日期：2026-11-09
> 定位：独立 Studio **垂直原型**。不承诺生产稳定性。
> 相关文档：`project-progress-and-version-roadmap.md` §4、`current-project-status.md`

## 1. 这个版本交付了什么

按版本路线图，`0.1.0` = 「独立 Studio 垂直原型」：核心领域、Web 工作台、基础导出与安全
AI 编辑链路可验证。范围包括：

- **领域与数据**：判别联合的文档模型、字段级校验、文档格式迁移链（当前 v4）、
  原子事务 + revision + 快照 + 事务日志 + 崩溃恢复。
- **布局与渲染**：absolute / stack / grid 三种布局（含命名区域与自动重复轨道）、
  fixed/fill/hug、padding/gap/对齐、文本测量契约、Canvas 2D 场景渲染。
- **编辑器**：页面、图层树、画布选择/框选/拖动/缩放/旋转/吸附、钢笔与矢量编辑、
  布尔组与蒙版、编组、属性面板、富文本与段落样式、Grid 轨道编辑、组件/变体/属性、
  原型预览（含滚动保持）、Token（颜色/数值/字体）、资源（含 SVG 与来源元数据）。
- **持久化与可靠性**：IndexedDB 与文件系统两个仓库、存储布局迁移链、历史版本与
  事务级回退、重建基线、JSON 导入导出、IndexedDB 自动备份、磁盘备份（10 分钟 → 5 分钟节流）。
- **AI**：OpenAI-compatible Planner、流式响应、dry-run 预览、结构审查、显式确认、
  过期计划拒绝、凭据只存会话存储。
- **导出**：HTML/CSS、SVG（含字体内联与子集化）、PNG（浏览器光栅化）。
- **质量**：视觉回归与画布像素回归、布局/导出/绘制预算门禁、a11y 对比度检查、
  键盘列表导航。

## 3. 可复现的人工验收清单

按顺序执行，每步记录「通过 / 不通过 + 现象」：

1. **新建与编辑**：`npm run dev:studio-web` → 新建项目 → 用矩形工具拖出一个形状 →
   改填充色与圆角 → 输入一段中文文本并改字号。
2. **撤销/重做**：连续 `Ctrl+Z` 回到空白，再 `Ctrl+Shift+Z` 回到最终状态；
   顶栏 revision 单调变化。
3. **刷新恢复**：等顶栏显示「已自动保存」→ 刷新页面 → 内容与 revision 保持；
   「历史 → 恢复报告」逐行可读。
4. **AI 预览/确认**：配置 OpenAI-compatible 端点与 API Key → 输入「把背景改成深色」
   → 计划预览（before/after、影响节点）→ 取消一次，确认一次；确认后撤销可还原。
5. **导出**：分别下载 HTML、SVG、PNG；HTML 在浏览器打开后布局与画布一致；
   SVG 里文字带 `font-family`（文档声明过的字体会内联）。
6. **项目级操作**：导出 JSON → 删除项目 → 重新导入 → 内容一致；重名导入给出建议名。
7. **日志与回退**：编辑若干次 → 「操作历史」回退到某一步 → revision 继续递增，
   再撤销可回到最新。
8. **（可选，Chromium）磁盘备份**：数据 → 磁盘备份 → 选一个空目录 → 确认写出
   一份 `ufira-backup-*.json`；5 分钟内再保存不重复写；刷新后目录仍在。

## 4. 已知限制

- **画布渲染**：Canvas 2D，文本测量依赖浏览器字体度量，跨平台字体差异会导致
  换行与 hug 尺寸不同；没有服务端/无 Canvas 环境的真实度量。
- **导出**：PNG 由 SVG 经浏览器光栅化；外部图片会污染画布（工作台内联的不会）。
  React / PDF 等格式未实现。
- **AI**：只支持 OpenAI-compatible 协议；真实 Provider 未逐家验收；结构审查覆盖
  删除/锁定/页面/历史还原/批量规模/硬编码颜色，不含跨页面一致性与可访问性。
- **MCP adapter**：stdio 与 HTTP 传输、Bearer、会话隔离、权限与审计已实现；
  没有 OAuth、多租户与 SSE 服务端推送。
- **Token**：颜色/数值/字体三类有渲染语义；没有分组、别名与主题切换，
  也没有从样式表/Figma 导入。
- **备份**：磁盘备份只在 Chromium 系可用；备份为明文 JSON，没有加密与跨设备同步。
- **存储布局**：只升不降；回滚需旧版本应用自行处理。
- **协作**：实时多人、评论、分享完全空缺（明确非目标）。

## 5. 数据丢失风险（必须告知使用者）

1. **浏览器存储会被清掉**：清空站点数据、隐私模式退出、配额回收都会带走项目。
   → 用 JSON 导出或磁盘备份；两者都建议定期做。
2. **IndexedDB 自动备份只有最近 3 份、10 分钟节流**，不覆盖「误删项目后马上发现」之外
   的场景；磁盘备份 10 份、5 分钟节流。
3. **迁移只升不降**：用旧版本打开新文档会被拒绝（这是刻意的保护），不要用旧版本覆盖。
4. **AI 计划不落盘直到确认**；确认前关闭页面不会留下半套改动。
5. **磁盘备份的浏览器端链路未做真实浏览器自动化验收**（工作台的 API Key 密码框会
   触发自动化工具的安全拦截）；§3 第 8 条需人工执行。

## 7. 升级与回滚

- 文档格式：v4（v1→v4 连续迁移，迁移历史写进文档）。
- 存储布局：文件系统 v2、浏览器 v3（`storage-layout.ts`，旧项目打开时自动升级，
  原始 manifest 备份到 `backups/manifest-v{旧版本}.json`）。
- 回滚：项目内容回滚走 `history.restore`（revision 递增、可再撤销）；
  应用版本回滚不在本版本承诺范围内。

## 8. 不在本版本承诺内

生产级渲染性能与大规模虚拟化、跨浏览器像素一致、加密备份、跨设备同步、
React/PDF 导出、实时协作、插件生态、正式安装包。
