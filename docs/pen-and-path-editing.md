# 钢笔与路径编辑（P3）设计

> 文档状态：生效中的 P3 规格
> 最后更新：2026-11-07
> 对标：Figma 的 Pen（钢笔）与 Edit Object（节点编辑）
> 前置：`editor-tooling-roadmap.md` 的 P2（归一化 M/L/Z 路径已落地）

## 1. 为什么这不是「加个 P 键」

P2 已经把 `vector` 节点做成了「归一化路径 + 盒子」，但路径只有 `M/L/Z`——所有图形都是
折线。钢笔要解决的是另外三件事：

1. **曲线表达**：`C`（三次贝塞尔）与 `Q`（二次）要进模型、渲染、命中、导出；
2. **多点交互**：钢笔一次路径要跨越多次点击，而现有手势模型是「按下—拖动—松手—提交」，
   一次手势 = 一个节点。必须引入一个**草稿状态**，它不进文档、可回退；
3. **曲线命中**：折线可以逐段求距离，曲线必须先离散化，否则点击判定与画面对不上。

## 2. 对标：Figma 的实际行为

| 操作 | Figma 行为 | 本轮取舍 |
| --- | --- | --- |
| `P` 进入钢笔 | 光标变钢笔，点击落点 | 采用 |
| 单击落点 | 角点（corner），无手柄 | 采用 |
| 按下并拖动 | 平滑点，拖出对称手柄（拖得越远曲率越大） | 采用 |
| 继续点击 | 上一段按手柄连成曲线，末段跟光标预览 | 采用 |
| 点回起点 | 闭合路径并结束 | 采用（8px 判定半径，悬停时高亮起点） |
| `Enter` / `Esc` | 结束当前路径 | 采用（`Esc` 在已有 ≥2 点时结束，否则丢弃退回选择工具） |
| 双击画布 | 结束当前路径 | 采用（第二次点击落在同一点时不重复落点） |
| `Shift` 拖动 | 手柄角度约束到 45° | 采用 |
| 在「已选中路径的线段」上点击 | 插入一个新锚点 | **顺延**（P3.3） |
| 在锚点/手柄上拖动 | 移动锚点、调整曲率；`Alt` 断开对称 | **顺延**（P3.3） |
| `Delete` 删除选中锚点 | 删除该锚点，路径重连 | **顺延**（P3.3） |
| Bend 工具（`B`） | 在线段上拖出一段弯曲 | 非目标（Figma 自己的新工具，语义未稳定） |

结论：**本轮交付「画」的能力，下一轮交付「改」的能力。** 先给用户一条能画曲线的钢笔，
比给一个能拖锚点但画不出曲线的半成品有价值。

## 3. 数据模型

### 3.1 命令扩展

```ts
export type PathCommand =
  | { command: "M" | "L"; point: PathPoint }
  | { command: "C"; control1: PathPoint; control2: PathPoint; point: PathPoint }
  | { command: "Q"; control: PathPoint; point: PathPoint }
  | { command: "Z" };
```

仍然**不支持 `A`（圆弧）**：各实现对椭圆弧的参数化不一致，圆弧用三段贝塞尔近似即可，
没必要为它引入一整套拟合代码。

### 3.2 坐标与包围盒规则

P2 的约定是「归一化到 [0,1]，相对节点盒」。曲线会带来一个新问题：**控制点可以在盒外**。

因此规则细化为：

- **在曲线上的点**（`M`/`L` 端点、`C`/`Q` 的终点）必须在 `[0,1]` 内（含 1e-6 容差）；
- **控制点**（`C.control1`、`C.control2`、`Q.control`）只要求是有限数，允许越界——
  否则一条向外鼓的弧就得先把盒子撑大再缩回去，来回插值会丢失精度；
- **节点盒 = 离散化后路径的紧包围盒**，不是「所有点的包围盒」。这样鼓出去的弧仍然落在
  盒内，选择框与命中包围盒都正确。

离散化统一用 `flattenPath`：每段三次曲线切成 16 段折线，`Q` 先升阶为 `C`。这个精度在
960×680 的画板尺度下误差 < 0.5px，视觉与命中都够用。

### 3.3 校验

zod refinement 复用同一个解析器：解析失败即拒绝写入。控制点越界仍然合法，但在曲线上的点
越界会被拒绝——这条规则让「盒子一定包含图形」这个不变式可被验证。

## 4. 交互状态机

### 4.1 钢笔（本轮）

```
idle
  │ pointerdown（空画布）
  ▼
placing ── pointermove（拖动）──▶ dragging-handle（实时改手柄）
  │ pointerup                          │ pointerup
  ├────────────────────────────────────┘
  │ 点击位置 ≈ 起点（≥2 点）
  ▼
committing ── onCommit(node.create) ──▶ idle
```

要点：

- **草稿是视图状态**：`anchors: Array<{ point, handleIn?, handleOut? }>` 存在 React state 里，
  不进文档、不涨 revision；只有 commit 时才发一条 `node.create`，因此一次路径 = 一次撤销；
- **手柄镜像**：拖动时 `handleOut = 光标 - 锚点`，`handleIn = -handleOut`（对称点）。
  P3.3 的 `Alt` 断开会改成两个独立手柄；
- **闭合判定**：指针到起点的距离 < `8 / zoom`，与手柄命中用的屏幕像素阈值一致；
- **结束方式**：`Enter`、`Esc`、双击、点击起点；点数为 1 时直接取消（一个点构不成路径）；
- **Shift**：拖手柄时把角度吸附到 45° 的整数倍，长度不变。

### 4.2 节点编辑（P3.3，下一轮）

- 选中 `vector` 节点后按 `Enter`（或双击）进入编辑态，显示锚点与手柄；
- 拖动锚点移动、拖动手柄调曲率，`Alt` 断开对称，`Delete` 删除锚点；
- 编辑期间实时预览，松手提交一条 `node.patch`（整条 `geometry.d`），与移动节点同样的
  事务粒度——拖动过程不写文档。

## 5. 渲染与命中

- **画布**：`C` → `bezierCurveTo`、`Q` → `quadraticCurveTo`，仍然在**绝对坐标**里描，
  不缩放上下文（P2 已确立的规则，避免描边被拉粗）；
- **命中**：`flattenPath` 后沿用 P2 的「闭合走奇偶规则、开放走到线段距离」，容差
  6px；离散化结果按 `d` 缓存，避免每次指针移动重算；
- **预览层**：草稿路径用虚线描边 + 锚点小方块画在 Canvas 覆盖层上，与框选/绘制预览共用
  `onAfterPaint`。预览只画已落下的锚点与「到光标」的一段，不写进文档。

## 6. 导出

- **SVG**：`C`/`Q` 直接输出（绝对坐标），不需要离散化——浏览器自己会画；
- **HTML**：沿用内联 `<svg viewBox>`，路径同样直接输出曲线命令；
- **PNG**：走 SVG 光栅化，无需额外处理。

**离散化只用于命中与包围盒，不用于输出**：导出产物保留原始曲线，缩放时不会露出折线。

## 7. 分阶段与验收

### P3.1 曲线数据层（✅ 已完成）

- `geometry.ts` 支持 `C`/`Q`：解析、校验、绝对化、序列化、`flattenPath`、`pathBounds`；
- 画布/命中/导出全部走新命令；
- 验收：曲线节点的画面、命中、SVG `d`、HTML 路径一致；越界控制点合法、越界端点非法；
  P2 的直线/多边形用例与 golden 全部不变。
- **结果**：解析器对 `C`（3 点）与 `Q`（2 点）做严格校验，端点必须在 `[0,1]`、控制点只要求
  有限；`flattenPath` 每段切 16 份，`pathBounds` 基于离散结果；画布用
  `bezierCurveTo`/`quadraticCurveTo`，命中走离散折线，导出直接输出 `C`/`Q`（不离散化）。
  `design-schema` 50 条、`design-export` 51 条通过，golden 未变。

### P3.2 钢笔工具（✅ 已完成）

- `pen` 工具 + 草稿状态机 + 预览层 + 快捷键 `P`；
- 验收：能画出开放折线、闭合多边形、带手柄的曲线；`Shift` 约束 45°；`Enter`/`Esc`/双击/
  点回起点都能结束；一次路径一次撤销；切换到别的工具会丢弃草稿。
- **结果**：`src/pen.ts`（纯函数：命令构建、几何归一化、闭合/去重判定、45° 约束、镜像手柄）
  与 `renderer/use-pen-tool.ts`（草稿状态机、指针事件、Enter/Esc 结束）。草稿路径用虚线
  画在 Canvas 覆盖层，锚点是白底方块，指针停在起点时起点变成圆环提示「点击闭合」。
  闭合路径给填充、开放路径只给描边（避免不闭合的曲线被填成怪面）。`pen.test.ts` 11 条。

### P3.3 节点编辑（下一轮）

- 编辑态、锚点/手柄命中与拖拽、`Alt` 断开对称、删除锚点、在线段上插入锚点；
- 验收：拖动锚点与手柄时实时预览、松手一条事务、`Esc` 放弃本次拖动。

## 8. 非目标

- 笔画/描边路径（Stroke path）与布尔运算（P4）；
- 文本转路径；
- 路径的吸附对齐（P3 只做 45° 角度约束）；
- 多路径合并、复合路径（一个 `vector` 只有一个子路径集，本轮不支持多子路径的编辑 UI）。
