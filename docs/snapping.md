# 智能锚点吸附规格

> 文档状态：生效中的实现规格
> 建立日期：2026-11-08
> 关联文档：`figma-gap-roadmap.md`、`current-project-status.md`

## 1. 要解决的问题

基础版吸附只做一件事：把拖动中的盒子与其它节点的**左/中/右、上/中/下**对齐线比较，
取阈值内最近的一条。够用，但有两个短板：

1. **看不出为什么吸过去了**——辅助线只有一条贯穿全屏的线，用户不知道是哪个角、
   哪条边对上了；
2. **等间距完全看不出来**——Figma 会在三个对象间距相等时给出「间距标注」并吸过去，
   这是画卡片列表、工具栏、栅格时最常用的对齐方式。

本轮把吸附升级为「智能辅助线」：锚点语义 + 等间距检测 + 可关闭。

## 2. 能力

| 能力 | 说明 | Figma 对应 |
| --- | --- | --- |
| 锚点对齐 | 角点 / 边中点 / 中心参与对齐，辅助线带上 `kind` | Smart guides |
| 等间距（夹在中间） | 拖动对象位于两个目标之间时，两侧间距相等就吸过去 | Equal spacing |
| 等间距（接在一串之后） | 一串已等距的目标之外，拖动对象接上去时保持同一间距 | Distribute smart guide |
| 间距数值标注 | 等间距辅助线上标出间距值（px） | 距离标注 |
| 阈值与开关 | 阈值可配；按住 **Alt** 临时关掉吸附 | Alt 临时关闭 |

**不做**：任意角度的旋转对齐、连接线锚点（connector handle）、与画布边缘的等距。

## 3. 数据结构

```ts
/** 一个盒子的锚点。 */
export interface Anchor {
  x: number;
  y: number;
  kind: "corner" | "edge" | "center";
  /** 这个锚点参与哪条轴的对齐：x / y / both。 */
  axis: "x" | "y" | "both";
}

/** 辅助线（旧字段保持不变，新字段全是可选）。 */
export interface SnapGuide {
  orientation: "vertical" | "horizontal";
  position: number;
  targetNodeId: string;
  kind?: "corner" | "edge" | "center" | "spacing";
  spacing?: number;
  segments?: Array<{ from: number; to: number }>;
  axis?: "x" | "y";
  cross?: number;
  targetNodeIds?: string[];
}
```

**向后兼容**：`SnapGuide` 的前三个字段是旧结构，`paintSnapGuides` 与
`use-canvas-drag` 的旧用法继续有效；新字段只在 `kind: "spacing"` 时出现。

锚点共九个：四角 + 四边中点 + 中心。**边中点只参与自己垂直的那条轴**——
左边中点参与水平对齐，但不该把竖直位置也吸过去（否则拖动会「粘」在两个方向上）。

## 4. 算法

### 4.1 锚点对齐

对每个目标、每个目标锚点、每个移动锚点：

- 若两者在某个轴上都参与（角点与中心参与两条轴，边中点只参与一条），算出差值；
- 差值在阈值内就是候选；每个轴取**绝对值最小**的那个（同值时先遇到的赢）；
- 辅助线的 `kind` 由两个锚点的种类决定：角点对角点 → `corner`，中心对中心 → `center`，
  其余 → `edge`。

### 4.2 等间距

两种情形：

1. **夹在中间**：移动对象左边有个目标、右边有个目标时，
   两侧间距不等就把它移到居中位置（两侧间距 = `(可用空间 - 自身宽度) / 2`），
   间距相等则原地不动但仍给提示。
2. **接在一串之后**：三个以上目标已经等距排列时，把移动对象放到这串的左边或右边，
   间距与那串保持一致。

候选的移动量必须也在阈值内——否则用户还差得远时不该被吸走。

### 4.3 冲突处理

同一根轴上，对齐与等间距都可能成立：**取移动量更小的那个**（相等时对齐优先）。
两个轴独立决策，所以「水平对齐 + 竖直等间距」可以同时出现。

## 5. 渲染

- 对齐辅助线：贯穿画布视口的 1px 线（按 zoom 换算保持屏幕宽度），与旧版一致；
- 等间距辅助线：两段带端点刻度的短线（画在移动对象的另一轴中心上），
  并在每段中点标出间距值（px）。

## 6. 已知限制

- **只处理轴对齐**：旋转过的节点用的是旋转后的 AABB，不做角度对齐；
- **等间距只看相邻的两个目标**：一串目标内部的空隙不参与；
- **等间距的判定容差是 1px**：间距相差 1px 以上就不算「相等」；
- **Alt 临时关闭**是唯一的交互入口，没有持久化的偏好开关；
- **多选拖动时用整体的包围盒**参与吸附，不是每个成员分别吸附。
